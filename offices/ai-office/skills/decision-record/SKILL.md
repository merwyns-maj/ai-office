# Decision record

```
Decision: <one sentence, present tense>
Context: <why this came up, 1–2 lines>
Options: <A — pro/con>, <B — pro/con> (2–3 options)
Chosen: <option> because <reason>
Consequences: <what gets easier, what gets harder, follow-up tasks>
Links: <task id, PR>
```

Keep it under 15 lines. A decision that reverses an earlier one names it.
