## How these are measured

- Stage hours: sum over every visit to the stage (rework included), from `status:` changes in task files on main and on PR head refs; commit author times, not work time.
- Turnaround: first non-todo status to first done; not recorded when no stage before done was seen.
- A sprint cell 'N (partial, k not recorded)' sums, or takes the median of, only the tasks with a recorded value; k tasks are missing.
- Reviewer REJECTs and Compliance BLOCKs: verdict lines in each task's Review log and Compliance sections, counted separately.
- Tasks with no Review log: REJECTs are review-to-build transitions in the status history (else from the sprint Close 'all with Reviewer PASS'); BLOCKs are 0 when the Design says 'Compliance: not flagged'; escalations come from the sprint Close ('without escalating').
- Escalations to Merwyn: lines saying 'escalated to Merwyn' in those sections.
- Specs approved first time: from the PMO approval heading (from Sprint 2 on); earlier tasks are not recorded.
- Sprint window: main squash-commit times from the sprint plan to the sprint close (or the next plan).
- Tasks per sprint: numbered task links in each closed sprint file. Open sprints are left out.
- Token usage: one line per agent run from the harness report, kept in `usage/<session>.jsonl` (`engine/schema/usage.md`). Only the total per run is reported; the input/output/cache split, the model used and the main session's own tokens are not. A run with no usage counts as a run and adds 0 tokens, never shown as 0.
- Token shares are of the session's recorded agent tokens. Runs that covered several tasks are counted once under 'Shared runs', never apportioned.
- 'not recorded' means the source is absent from the history available; it is never blank or 0.
